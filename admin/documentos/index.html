Criar o cofre

Uma vez só. A chave do cofre nasce neste browser e fica fechada com uma frase-passe que só tu sabes. Depois abres o cofre neste ou noutro aparelho com essa frase.

Pelo menos 16 caracteres, com palavras diferentes e que não sejam do site. Cinco palavras ao acaso são fáceis de lembrar e difíceis de adivinhar. Guarda-a nas Palavras-passe do aparelho.

A frase-passe começa ou acaba com um espaço. Conta como parte dela.

Fica guardada uma chave que não sai deste browser. Quem tiver este aparelho desbloqueado abre o cofre.

  • Se perderes a frase-passe, ninguém a recupera, nem eu. Crias um cofre novo e publicas outra vez no computador; as versões antigas deixam de abrir.

Para criar o cofre é preciso o token do GitHub, o mesmo da página Espaços. Se este browser ainda não o tiver, peço-o a seguir.

    Criar um cofre novo
    
    
    • Para quando a frase-passe se perdeu, ou quando alguém pode saber a frase-passe. O cofre novo tem outra chave: tudo o que já está publicado deixa de abrir aqui. No computador, publicas outra vez a versão atual de cada documento; as versões antigas perdem-se. O que já foi publicado fica em cópias públicas com a chave antiga: o cofre novo protege o que vier depois.
