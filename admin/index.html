Espaços do fato e do capacete

Reserva, vende e liberta espaços com o site no ar. Cada ação fica guardada no GitHub e o site atualiza-se sozinho em 1 a 2 minutos.

Criar a chave de acesso (uma vez)

  1. Abre github.com/settings/personal-access-tokens/new (botão abaixo) com a conta dona do repositório.
  2. Em «Repository access» escolhe «Only select repositories» e depois rgvduarte/carmo. Validade: 90 dias.
  3. Em «Permissions» junta Contents e escolhe Read and write. O Metadata fica em Read sozinho.
  4. Carrega em «Generate token» e copia o código (começa por github_pat_). O GitHub só o mostra uma vez: guarda-o nas Palavras-passe ou nas Notas do telemóvel e cola-o aqui em baixo.
Criar token no GitHub ↗

Guarda o token neste telemóvel, para todo o site gocarmo.com. Sem isto, ao fechar o separador tens de colar o token outra vez.

Se o GitHub não te deixar escolher rgvduarte/carmo (és colaborador e não dono), cria um token clássico só com public_repo e 7 dias de validade. Atenção: esse token pode escrever em todos os repositórios públicos a que a tua conta tem acesso, não só neste. Apaga-o quando acabares.

Sem token à mão? Usa o formulário do GitHub.

Treinos no site: Ligar o Strava (uma vez, sem token).
