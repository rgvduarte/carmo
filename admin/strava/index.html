Ligar o Strava

Cinco passos, uma vez só. Depois os treinos do Gonçalo entram no site sozinhos, todas as manhãs.

  • Precisas de duas contas neste telemóvel: o Strava do Gonçalo e o GitHub rgvduarte. Só o dono do repositório pode guardar os secrets no passo 4.

1Cria a aplicação no Strava

Client ID

Abre a página de API do Strava e entra com a conta do Gonçalo.

Abrir o Strava ↗

Se abrir a app do Strava em vez da página: carrega sem soltar no botão e abre num separador novo, ou copia o endereço e cola-o na barra do browser.

Endereço
www.strava.com/settings/api

Preenche o formulário com estes valores:

Application Name
GOCARMO site
Category
Visualizer
Website
https://gocarmo.com
Authorization Callback Domain
gocarmo.com

O resto pode ficar em branco. Aceita os termos e carrega em «Create». Se o Strava pedir um ícone, usa o símbolo GOCARMO.

Aparece no Strava em «My API Application», ao lado de Client ID. Só números.

    2Autoriza

    Autorizado no Strava.

    No Strava, entra com a conta do Gonçalo, deixa as duas opções marcadas e carrega em «Authorize». O Strava volta a esta página sozinho.

      Se o Strava mostrar «Bad Request» com client_id, corrige o Client ID no passo 1. Com redirect_uri, o Authorization Callback Domain da aplicação tem de ser gocarmo.com.

      3Liga a conta

      Ligado como

      Volta à página da aplicação no Strava, carrega em «Show» ao lado de Client Secret, copia e cola aqui. Não fica guardado.

      Abrir a aplicação no Strava ↗

      Se abrir a app do Strava: carrega sem soltar no botão e abre num separador novo, ou copia o endereço e cola-o na barra do browser.

      Endereço
      www.strava.com/settings/api

      São 40 caracteres, de 0-9 e a-f.

        Ligado como

        • Confirma que é a conta do Gonçalo. Para trocar, sai do Strava neste browser e autoriza outra vez.

        4Guarda no GitHub

        Os três secrets estão no GitHub.

        Cria um secret por linha: o nome vai para «Name», o valor para «Secret», e carrega em «Add secret». Repete para os três.

        Novo secret no GitHub ↗
        1. STRAVA_REFRESH_TOKEN
        2. STRAVA_CLIENT_ID
        3. STRAVA_CLIENT_SECRET

        Começa pelo STRAVA_REFRESH_TOKEN: é o único que não voltas a encontrar no Strava. O Client ID e o Client Secret estão sempre na página da aplicação.

        Entra no GitHub com a conta dona do repositório (rgvduarte): só ela pode criar secrets. Se um nome já existir, abre-o na lista e cola o valor novo.

        Não feches nem recarregues esta página antes de criares os três. Se recarregar, os valores perdem-se e tens de autorizar outra vez no passo 2.

        5Corre a primeira sincronização

        No GitHub, carrega em «Run workflow» e depois no botão verde «Run workflow». Em poucos minutos, os treinos aparecem no site.

        Correr no GitHub ↗

        A partir daí, corre sozinha todas as manhãs.

        • Antes de acabar, abre a corrida e espera que fique verde. Se o passo «Build data/strava.json» disser «skipping», o nome STRAVA_REFRESH_TOKEN falta ou está mal escrito. Se ficar vermelha, confirma os três nomes e valores. Corrige no GitHub com os valores desta página e corre outra vez.

        Esta página só fala com o Strava. Só guarda o Client ID, neste separador, até carregares em «Limpar» ou «Acabei». O Client Secret e os tokens nunca ficam guardados.
